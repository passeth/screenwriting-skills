## 1. 《만춘》(1949, 103장면)

**한 문장 이야기**: 가마쿠라의 홀아비 교수 슈키치(56)는 시집가려 하지 않는 딸 노리코(27)를 떠나보내려고, 자신이 재혼한다고 거짓말한다. 노리코는 분노와 상실 끝에 맞선을 받아 시집가고, 아버지는 홀로 사과를 깎으며 결혼식 밤을 보낸다.

| 단락 | 장면 | 내용 | 기능 |
|---|---|---|---|
| 서 | 1–8 | 기타가마쿠라 역, 다회, 마당의 햇그림자, 꾀꼬리 | 빈 숏으로 계절과 “고요”를 세움; 아키코가 처음 화면에 들어옴(대사 없음) |
| 설정 | 9–18 | 슈키치와 핫토리가 원고를 씀; 노리코의 귀가; 부녀가 전차에 함께 탐 | “차 따라, 차 따라”로 부녀 관계의 느슨함과 의존을 확정 |
| 가짜 실마리 A | 21–26 | 긴자에서 오노데라와 마주침→다키가와→“재혼은 더러워” | 지뢰 매설: 노리코가 제 입으로 “재혼”을 부정함 |
| 가짜 실마리 B | 27–30 | 핫토리와 자전거, “실이 끊이지 않는 단무지” | 관객이 핫토리를 상대로 오해하게 함 |
| 첫 추진 | 31–37 | 고모가 아버지에게 노리코의 핫토리 생각을 물어보라 부추김→“핫토리는 결혼한다” | 가짜 실마리 파산; 희극 리듬 |
| 공백 | 38–42 | 카페에서 표를 돌려줌→극장의 빈 좌석→노리코가 마루노우치를 홀로 걸음 | 생략법: 빈 자리로 적막을 표현 |
| 대조자의 등장 | 43–48 | 아야의 방문: “시집갔다 돌아온 물건”; 동창회 뒷말 | “나 시집 안 가”가 처음 명시됨 |
| 둘째 추진 | 49–52 | 고모 집: 맞선을 제안→거절→아키코를 아버지의 후처로 내놓음 | 중점: 노리코 “괜찮겠지요, 아빠만 이의가 없으시면”(차갑게) |
| 냉전 | 53–57 | 노리코가 아버지를 외면함; “장 보러……” 하며 쓸쓸히 떠남 | 대사가 거의 없음 |
| 방증 | 58–61 | 이웃이 핫토리의 결혼 답례품을 받음 | 제삼자 시점으로 확인 |
| 클라이맥스 전 | 62–66 | 노가쿠도: 아버지가 아키코에게 고갯짓; 노리코가 점점 불쾌해짐 | 대사 없는 클라이맥스 |
| 폭발 | 67–68 | 아야의 집: 생크림 케이크 싸움 | 전위 |
| 패를 뒤집음 | 69–73 | “누가 아빠를 돌봐 준다면”→추궁→“응”→이층으로 뛰어 올라가 울음 | 거짓말이 자리를 잡음 |
| 이완 | 74 | 하치만궁에서 고모가 지갑을 주움 “이 혼사는 꼭 되겠다” | 희극 조미＋길조 |
| 결정 | 75–82 | 아야가 혼인을 권함→승낙→아버지가 “체념해서 가는 건 아니지?”라고 물음 | 결정은 마지못한 것 |
| 작별 여행 | 83–93 | 교토: 오노데라에게 사과; 료안지 “딸 키우는 건 정말 재미없어”; 여관의 밤 이야기→긴 독백 | 전편 유일한 긴 독백 |
| 에필로그 | 94–103 | 결혼식 날 거울 앞→무릎 꿇고 작별→빈 방→아야의 입맞춤과 “예쁜 거짓말”→사과 껍질이 끊기고→밤바다 | 진실은 제삼자가 찔러 밝힘 |

### 범례 A: 세 개의 “응”(71장면)
```
노리코: 그럼 아빠도 오노데라 아저씨처럼……
슈키치:（모호하게）응……
노리코: 재혼하시는 거예요?
슈키치: 응……
노리코:（더욱 날카롭게）재혼하실 거죠?
슈키치: 응.
노리코: 오늘 그분이요?
슈키치: 응.
노리코: 정말이에요?…… 정말이에요?
슈키치: 응.
노리코: ……（점점 견딜 수 없어져）
갑자기 일어서서, 도망치듯 떠난다.
```

### 범례 B: 대사 없는 클라이맥스(62장면 노가쿠도)
```
슈키치가 창본을 보다가, 문득 맞은편 누군가에게 고갯짓으로 인사한다.
노리코가 알아채고, 그쪽을 바라본다——
미와 아키코다, 맞은편 자리에 앉아 있다.
그리하여 노리코도 고개를 숙여 인사한다.
아키코도 우아하게 말없이 예를 갖춘다.
슈키치는 계속 창본과 무대를 주시한다. 노리코 쪽은 아버지와 아키코 사이의 왕래가 몹시 거슬려, 시선이 저도 모르게 아키코 쪽으로 향한다.
단정하고 아름다운 아키코가 무대를 응시한다.
그 뒤로 아버지는 아키코 쪽을 보지 않았고, 아키코도 다시 아버지 쪽을 보지 않았으나, 노리코는 어쩐지 마음이 편치 않다.
점점 더 불쾌해 보인다.
```

### 범례 C: 전위된 말다툼(68장면)
```
노리코가 화가 나서, 이미 손에 들었으나 아직 손대지 않은 케이크 접시를 “펑!” 하고 내려놓는다.
아야: 안 먹어?
노리코: 먹기 싫어!
아야: 제발 먹어!
노리코: 나는 먹기 싫어!
아야: 맛있다니까!
노리코: 됐어!
아야: 뭐야, 겨우 이만큼인데! 내가 손수 만든 거야, 먹어!
노리코: 난 안 먹어!
아야: 먹으라니까! 안 먹어도 먹여 줄 거야!
노리코: 나는 안 먹어!
아야: 미쳤어! 안 먹으면 그만이지!
노리코:（화가 나서 말이 나오지 않음）……
아야: 내가 말했지, 너는 진작 시집갔어야 해.
```

### 범례 D: 유일한 긴 독백(93장면, 발췌)
```
슈키치: ——아빠는 이미 쉰여섯이다. 아빠의 인생은 이미 끝자락인데, 너희는 이제 시작이야.…… 이것이 인간 삶의 역사적 법칙이지.
……결혼한다 해도, 처음부터 행복한 것은 아닐지도 몰라.…… 행복은 거기 서서 기다려 주지 않아. 스스로 만들어야 해. 결혼 그 자체가 행복은 아니야——신혼부부가 함께 새 인생을 세워 가는, 그 과정 안에 행복이 있는 거야.…… 네 엄마도 처음부터 행복하지는 않았어.…… 아빠는 여러 번, 부엌 구석에서 울고 있는 엄마를 보았지. 그러나 네 엄마는 견뎌 냈어——
```

### 범례 E: 결말(100–103장면)
```
아야: 난 그렇게 예쁜 거짓말은 못 해.
슈키치: 뭐?
아야: 난 그렇게 예쁜 거짓말은 못 해.
슈키치: 하하하하——（그리고 쓸쓸하게）어쩔 수 없지, 아저씨 인생에도 이렇게 큰 거짓말은 처음이야……
……
슈키치가 홀로 적적하게 예복 상의를 벗어, 문틀의 옷걸이에 건다. 탁탁 먼지를 털고 나서, 힘없이 의자 곁으로 가 앉는다. 문득 탁자 위의 사과가 보여, 집어 깎는데, 사과 껍질이 얼마 가지 않아 끊긴다. 슈키치는 그대로 꼼짝 않고 앉아 있다.

103　밤의 바다
완만하고 거대한 물결이, 찰찰 기슭으로 밀려왔다가 물러간다……
```

## 2. 《맥추》(1951, 145장면)

**한 문장 이야기**: 기타가마쿠라 삼대가 한집에 사는 마미야 가에서, 스물여덟 살 딸 노리코에게 이사가 “조건이 아주 좋은” 혼담을 소개한다. 온 집안이 조사와 설득에 나서지만, 그녀는 이웃 과부의 한 마디 “네가 며느리가 되어 주면 얼마나 좋을까” 뒤에, 갑자기 아이를 데리고 곧 아키타로 떠날 의사 겐키치에게 시집가기로 한다. 가족은 어리둥절하다 받아들이고, 온 집안이 기념촬영을 한 뒤 흩어진다.

| 단락 | 장면 | 내용 | 기능 |
|---|---|---|---|
| 서 | 1–19 | 새벽, 온 집안이 아침을 먹고 제각기 나감; 할아버지가 손자의 손톱을 깎음 | 한 끼 아침으로 삼대 일곱 입을 세움 |
| 세계 | 20–25 | 이사실; 아야의 방문; 오빠·여동생·올케가 덴푸라를 먹음 | 고이치의 “권하면서도 못 마시게 하는” 성격을 여동생이 면전에서 요약 |
| 큰아버지의 방문 | 26–45 | 귀가 어두운 모키치; 아이가 “바보”라고 외침; 하세 대불; 가부키 | 귀먹음＝듣지 못하는 가족 |
| 혼담 | 40–46 | 다카코 부부가 당근을 두고 싸움; 이사가 혼담을 내고 골프 사진을 줌 | 기혼의 말다툼＋미혼의 혼담 |
| 조사 | 47–58 | 아야의 어머니가 “경사”를 전함; 고이치 부부가 침상에서 상의; 슈키치 “서둘러야지” | 혼사가 노리코가 없는 자리에서 추진됨 |
| 혼인 피로연 후 | 59–61 | “행복 인종” 논쟁; 고이치가 미닫이 뒤에 숨어 세 번 고개를 내밈 | 형이 문 뒤에 숨어 올케를 지휘함 |
| 신용조사 | 62–64 | 신용조사소가 다녀감; 쇼지 “그는 돌아오지 않아” | 희극에서 전쟁 외상으로 가라앉음 |
| 일요일 | 65–75 | 잉어 깃발; 아이가 궤도를 깔음; 노부부가 줄 끊긴 풍선을 봄 | 중점의 빈 숏: “지금이 우리 집에서 가장 좋은 때일지도” |
| 서브플롯의 폭발 | 76–105 | 케이크 구백 엔; “궤도”는 사실 빵→빵을 차고→맞아서→가출→찾아냄 | 어른이 준 선물은 아이가 원한 것이 아님 |
| 전환의 방아쇠 | 106–108 | 겐키치가 어머니에게 아키타로 간다고 알림 | 시간의 압박 |
| 결정 | 109–117 | 니콜라이당 카페에서 쇼지와 보리 이삭 편지를 회상; 다미의 한 마디 헛된 생각→“나도 괜찮다면” | 결정의 한순간, 겐키치는 자리에 없음 |
| 가족의 반응 | 118–121 | 한밤 온 집안 회의 “정말 아니야?”“아니.”; 부모가 힘없이 이층으로; 노리코가 거울 앞에서 립스틱을 바름 | 반응 줄서기 |
| 소화 | 122–135 | 다미가 회사에 와 확인; 시게의 불평; 슈키치가 건널목에서 한숨; 아야의 아키타 사투리; 바닷가에서 올케와 여동생의 “검약 시합” | “가위가 바로 눈앞에” |
| 작별 | 136–140 | 온 집안 기념촬영＋부모만 따로 촬영; 스키야키 송별; 노리코가 이층으로 도망쳐 울음 | 기념촬영＝가족이 마지막으로 온전한 한 번 |
| 에필로그 | 141–145 | 야마토의 보리밭; 노부부가 남의 집 시집보내는 것을 봄 | 주인공은 없고, 남의 결혼식으로 거둠 |

### 범례 A: 결정의 한순간(113장면)
```
다미: 별일 아니에요, 호호, 내가 혼자 좋게 생각한 거지. 겐키치에게 너 같은 처녀가 며느리가 되어 주면 얼마나 좋을까 했지!
노리코: 아.
다미: 미안해요, 이건 내 혼자 꿈같이 생각한 거야…… 화내지 말아요.
노리코: 정말이에요? 아주머니——
다미: 뭔데?
노리코: 저에 대해, 정말 그렇게 생각하셨어요?
다미: 미안해요, 그러니까 화내지 말라고.
노리코: 아주머니, 저처럼 시집도 못 가는 아이도 괜찮아요?
다미: 아?（제 귀를 의심하는 듯）
노리코: 나도 괜찮다면……
다미:（저도 모르게）정말?（목소리도 커진다）
노리코: 네.
```

### 범례 D: 빈 숏 속의 주제(75장면)
```
슈키치: 참 빠르구나…… 고이치가 장가들고, 손자가 태어나고, 이어서 노리코가 시집가지. 어쩌면 지금이 가장 즐거운 때일지도 몰라.
시게: 그럴지도…… 그래도 앞으로는 또……
슈키치: 생각은 그만두지. 사람은 욕심이 나면 끝도 없지.——아, 참 맑은 일요일이구나……
시게: 얘, 저것 봐——（맞은편 하늘을 가리키며）
슈키치: 음?（하늘을 봄）
줄 끊긴 풍선이 허공을 향해 날아간다.

## 3. 《동경 이야기》(1953, 176장면)

| 에필로그 | 118–121 | 역에서 성냥 두 개비; “구와나 두 장”; 밤기차에서 도시락을 함께 먹음 | 말이 거의 없는 화해 |

### 범례 A: 비밀을 관객에게 열어 보임(27장면)
```
고마주로: 있잖아…… 기요시는, 나를 어떻게 보고 있나?
오요시: ……
고마주로: 아직도 아버지는 죽은 줄 아나? 정말 나를 네 오라비로 아나?
오요시가 시선을 내리깔고 대답하지 않은 채, 술주전자를 가져온다.
오요시:（술주전자를 들어）드세요.
고마주로: 오.（술을 받음）
오요시: 당신은, 마음이 편치 않겠지?
고마주로: 왜?
오요시: 기요시 일 때문에.
고마주로: 그걸 말하면 어쩔 수가 없지. 배우 아비는 없는 편이 낫다.
```

### 범례 B: 부자의 가치관 다툼(44장면)
```
기요시: 그런데, 마루바시 주야 같은 건 사회적 의미가 전혀 없잖아요!
고마주로: 사회적 의미가 뭔데?
기요시: 요즘 사회와의 연관이죠.
고마주로: 무슨 소리를 하는 거야, 마루바시 주야는 옛날 사람이야!
기요시: 그러니까 삼촌은 안 된다니까요, 너무 낡았어요……
고마주로: 헤이, 잘난 척은! 허튼소리만 하고. 낡은 것도 나쁘지 않아. 그런 관객은 아주 즐거워하거든.
기요시: 관객이 즐거우면 그만인가요?
고마주로: 그만해, 연기 이야기는 이제 그만.——（낚싯대를 들어）이것 봐 이것 봐, 미끼를 또 먹혔잖아?
```

### 범례 C: 거울로 봄(48장면)
```
야타조: 좌장님이 낚시 가신 거 아니에요?
스미코:（의아하게）낚시?
야타조: 아, 이발소에서 면도할 때, 젊은이와 낚싯대를 들고 지나가는 걸 봤어요.
스미코: 젊은이?
야타조: 모르세요? 우체국 사람이라던데요——거울로 봤어요.
```

### 범례 D: 빗속 맞대거리의 세 단 상승(74장면, 발췌)
```
스미코: 잊으셨어요? 오카야 때! 누가 힘써 구해 줬는지 기억나요? 도요카와도 마찬가지였잖아요! 재수 없으면 와서 애원하고, 나한테 굽실거리는 게 누구예요!
……
고마주로: 뭐라고! 허튼소리! 너는 네가 뭔 줄 알아, 너! 예전을 생각해 봐! 너는 야마나카 온천의 기생이 아니었냐! 기어이 나한테 와서, 여기 눌러앉아 안 가고, 겨우겨우 너를 제 몫을 하게 가르쳤지.
……
고마주로: 내 아들은, 너희들과는, 아예 다른 인종이야. 인종이 달라! 똑똑히 기억해 둬! 멍청이!
빗물이 배수관을 따라 사납게 떨어진다.
```

### 범례 E: 도구의 고백(90장면)
```
가요:（얼굴을 돌리고 슬프게）나는 좋은 여자가 아니야.（돌아보며 기요시를 보고, 눈에 눈물을 머금고）나는 값싼 여자야.
기요시: 무슨 소리를 하는 거야!
가요: 처음엔 속일 생각이었다.
기요시: ——?
가요: 나는 너를 전혀 몰랐어. 언니가 부탁해서, 너를 만나러 온 거야…… 너는 걸려들기만 하면 된다고 생각했어.
기요시: 그건 내가 상관할 바가 아니야! 처음엔 어떻게 생각했든, 난 상관없어! 너는 어떻게 생각하는 거야! 너 자신은!
```

### 범례 F: 신분이 밝혀짐(115장면)
```
오요시:（기요시에게）아들아, 이 사람이 누군지 아니…… 이 사람이 네 아빠야…… 친아버지야! 어떻게 이럴 수가 있니!
기요시가 충격받아 고마주로를 본다.
기요시: ——그렇구나, 과연…… 그럴지도 모른다고 생각했어……
고마주로는 무슨 말을 해야 할지 몰라, 그를 향해 희미하게 쓴웃음을 짓는다.
……
기요시: 왜 이제 와서 갑자기 나타나는 거야!（오요시에게）엄마, 왜 이제 와서 갑자기 이런 말을 하는 거야! 이런 아버지는 필요 없어! 꺼지라고 해! 꺼지라고 해! 꺼져!
……
고마주로:（한숨）그 녀석 말도 맞지…… 맞는 말이야——갑자기 나타나서, 이게 네 아버지라고 하면, 통하지 않는 것도 당연하지.
```

### 범례 G: 성냥(119장면)
```
고마주로가 어색한 표정으로 앉아, 담배 한 대를 물었으나 성냥이 없어, 위아래로 찾는다. 스미코가 말없이 일어나 와, 성냥 한 개비를 그어 건넨다. 고마주로가 놀라 그를 한 번 보고, 또 찾는다.
스미코가 거의 타 버린 성냥을 버리고, 둘째 개비를 다시 그어 건넨다. 고마주로가 다가가 불을 붙이고, 스미코가 그 곁에 앉는다.
스미코: 좌장, 어디로 가세요?
고마주로는 말없이 담배를 피운다.
스미코:（담배를 꺼내）불 좀.
말하며 고마주로의 담배를 가져간다.
……
고마주로: ——한판 걸어 볼까……
스미코: 네?
고마주로: ——다시 판을 짜고 한바탕 해 볼까……
스미코: 그래, 한바탕 하죠. 제대로 해 봐요.
……
스미코: 구와나 두 장——
고마주로: 그쪽 짐은 잊지 말고.
스미코가 몸을 돌려 고개를 끄덕이며 희미하게 웃고, 이어서 표를 산다.
```

## 5. 《추일화》(1960, 110장면)

**한 문장 이야기**: 세 옛 동창(마미야, 다구치, 히라야마)이 죽은 친구의 칠주기 기일에 죽은 친구의 딸 아야코(24)의 혼처를 보기로 한다. 아야코가 “어머니를 두고 떠날 수 없어”라는 이유로 시집가지 않자, 세 사람은 “먼저 어머니 아키코(45)를 재혼시키자”는 꾀를 내고, 홀아비 히라야마를 내민다. 소식이 아야코 귀에 들어가 모녀가 갈라지고, 마지막에 아키코는 딸에게 자신이 재혼하고 싶다고 거짓말하여 딸을 시집보내고, 자신은 홀로 아파트에 남는다.

**《만춘》과의 거울**: 남는 부모가 아버지→어머니; 거짓말 “아버지가 재혼한다”→“친구들이 어머니 대신 재혼을 꾸밈/어머니는 스스로 재혼하고 싶지 않다고 말함”; 추동자가 한 사람→세 사람의 합의 소동; 대상이 등장하지 않음→두 번 등장; 딸의 친구가 이혼한 속기사→초밥집 딸; 결말이 사과를 깎음→하오리를 접음; 하라 세쓰코가 딸을 연기함→어머니를 연기함.

| 단락 | 장면 | 내용 | 기능 |
|---|---|---|---|

| 결의 | 6–9 | 세 사람이 면전에서 아야코에게 물음; 떠난 뒤 “그 엄마가 더 좋아”, 약방 옛일 | 동기＝죽은 친구의 아내를 은밀히 사모함 |

| 혼담 | 15–28 | 장어덮밥으로 고토를 꺼냄; 아키코가 파이프를 줌; 아야코 “거절하죠” | 이유 “엄마와 둘이 화목하게” |

| 여행 | 91–103 | 이카호; 깊은 밤 “엄마는 역시 혼자 있고 싶어……”; 하루나코 “마지막이야” | 진위가 갈리지 않는 거짓말 |
| 결혼식 | 104–105 | 접수처와 사진 | 결혼식＝사진 |
| 에필로그 | 106–110 | 세 사람 조 “나만 한 번 이용당했지”; 유리코가 아키코를 보러 옴; 하오리를 접음; 빈 복도 | 희극＋고독이 병치됨 |

### 범례 A: 세 사람 조의 동기(9장면)
```
다구치: 참 아름답군, 과연……
히라야마: 응, 이 나이 처녀와 이야기하는 게, 내가 제일 좋아.
다구치: 그런 뜻이 아니야. 물론 딸도 괜찮지.
마미야: 그 엄마 말이지?
다구치: 응, 조금도 안 변했어.
마미야: 참 아름답군.
……
다구치: 그렇게 좋다니. 뭐랄까? 그렇게 아름다운 아내가 있으면, 남편도 일찍 죽어야 마땅하지.
```

### 범례 B: 주제문(57장면)
```
아야코: 아저씨, 저는, 사랑과 결혼은 따로 생각해야 한다고 생각해요.
마미야: 오——그게 무슨 뜻이지?
아야코: 무슨 뜻이냐면, 그게……
마미야: 그러니까 혼외연애도 괜찮다는 건가?
아야코: 그런 불순한 생각은 없어요.
마미야: 아, 그런가? 실례 실례——
아야코: 제 뜻은, 사랑과 결혼이 일치할 수 있다면, 그보다 좋을 수는 없죠. 그러나 일치하지 않는다 해도, 그것이 불행이라고는 생각하지 않아요. 그래도 충분히 즐거운 거죠. 이 세상, 그런 경우가 더 많지 않나요?
```

### 범례 C: 일을 그르침(65장면)
```
다구치: 전혀 가망이 없어. 재혼할 생각은 아예 없다고, 전혀 없다고 하더군. 처음부터 끝까지, 죽은 남편 이야기만 했어.
……
다구치: 그런 말이 있잖아. 비 속의 수심 어린 해당화——그것만이 아니라, 사과까지 깎아 주더군, 그 하얀 손으로……
마미야: 그래서, 먹었어?
다구치: 응, 먹었지, 아주 맛있더군.（주머니에서 파이프를 꺼내）이것도 받았어.
마미야: 이 녀석, 도대체 뭘 하러 간 거야?
……
히라야마: 결과는?
다구치:（멈춤. 이어서 혼잣말처럼）——아이고, 서두를 일이 아니지……
히라야마: ——?
마미야:（역시 혼잣말처럼）응, 서두를 일이 아니지……
히라야마가 기운 없이 땅콩을 먹는다.
마미야와 다구치가 둘 다 파이프로 코를 문지른다.
```

### 범례 D: 무고한 이가 비난받음(72장면)
```
아야코: 엄마가 재혼하세요?
아키코:（놀라며）아? 재혼?
아야코: 왜 저한테 숨기시는 거예요!
아키코: 무슨 일이야!
아야코: 다 알아요!
아키코: 네가 뭘 안다는 거야! 무슨 일이야? 엄마는 전혀 모르겠는데——
아야코: 속이지 마세요. 엄마가 이러면, 아빠에게 미안하지 않으세요? 히라야마 씨는 아빠 친구가 아니에요!
……
아야코: 더러워! 이런 건 제일 싫어!
```

### 범례 E: 바깥사람의 심판(89장면)
```
유리코:（여전히 서서, 어조가 아주 준엄하게）여쭙겠습니다, 도대체 왜 있지도 않은 일을 말씀하시는 거죠?
마미야: 무슨 일——
유리코: 미와 아주머니 재혼 일이에요.
마미야: 오, 그 일——
유리코: 오가 뭐예요, 아주머니는 전혀 모르시는데, 왜 아야코에게 그런 말씀을 하신 거죠? 왜 고요한 연못에 돌을 던져 일을 만드는 거죠? 그 일 때문에 아야코가 몹시 괴로워했어요. 왜 그런 일로 남의 집안 화목을 어지럽히는 거죠? 그걸 여쭈러 온 거예요, 대답해 주세요.
남자들이 서로 얼굴을 바라본다.
```

### 범례 F: 어머니의 마지막 밤(101장면)
```
아키코: ——있잖아 아야, 엄마 재혼 일에 대해, 네가 더럽다고 했지. 그렇게 말했지.
아야코: ——? 아, 그건 이제 괜찮아요.——죄송해요, 그런 쓸데없는 말을.
아키코: 아니, 사실 엄마도 그렇게 생각해.
아야코: ——?
아키코: 엄마는 역시 혼자 있고 싶어.
……
아키코: 응, 네 아빠 한 사람이면 충분해. 앞으로도 네 아빠와 둘이 살아갈 거야. 그것으로 됐어. 이제 와서, 다시 산기슭부터 오르라니, 나는 지쳤다.
……
아키코: 참, 그리고, 널 시집보내려고 엄마가 거짓말을 했다고 생각하지 마라.
아야코가 눈물을 닦는다.
```

### 범례 G: 결말(108–110장면)
```
히라야마: 그건 좋지, 그런데 나만 한 번 이용당했지. 너희들은 좋구나, 파이프를 다 받았잖아.
다구치: 이거?——너도 꽤 남는 장사였지, 좋은 꿈도 꿨잖아?
마미야: 그런데, 세상일이란, 여럿이 모이니까 도리어 복잡해졌지, 알고 보니 아주 단순한 일이었는데.
……
109　그날 밤　아파트
아키코가 예복을 걸고 있다.
아키코 혼자 쓸 이불이 깔려 있고, 그녀는 쓸쓸하고 힘없이 보인다.
……
이어서 침실로 돌아와, 멍하니 한숨을 한 번 쉬고, 몸의 하오리를 벗어, 힘없이 접는다.
110　복도

## 6. 《만추》(1962, 98장면, 오즈의 유작)

**한 문장 이야기**: 홀아비 히라야마(57)가 딸 미치코(24), 작은아들 가즈오와 함께 산다. 옛 동창 가와이가 딸을 시집보내라 재촉하고, 동창회에서 선생 “호로”와 다시 만나, 선생이 “편하자고” 딸을 곁에 두었다가 지금은 부녀가 작은 국숫집에서 처량하게 지내는 것을 보고, 히라야마는 딸을 시집보내기로 마음을 굳힌다. 딸이 좋아한 미우라에게는 이미 상대가 있고, 미치코는 맞선을 받아 시집간다. 결혼식 밤 히라야마는 홀로 바에 가 군함행진곡을 듣고, 집에 돌아와 “외톨이로구나”를 흥얼거린다.

### 범례 A: 거울이 열림(27장면)
```
사쿠마:（여전히 기분 좋게 중얼거리며）아, 유쾌하구나…… 너무 유쾌해! 음…… 히라야마! 가와이!
외친 뒤에 갑자기 풀이 죽는다.
도모코가 곁에서 보다가, 문득 슬픔이 치밀어, 얼굴을 가린다.——멀리서 속된 레코드 곡이 들려온다……
```

### 범례 B: 참회(57장면)
```
사쿠마: 아아, 적적하구나…… 슬프구나.——결국 인생이란 혼자인 거야…… 외톨이로구나.
가와이와 히라야마가 서로 얼굴을 바라본다.
사쿠마: 아아, 내가 잘못했어…… 한 가지를 잘못했지…… 나만 편하자고 해서는 안 됐어……
히라야마: 무슨 일입니까?
사쿠마: 아아, 내 딸이야.——편하자고 딸을 곁에 두고 부려 먹었어…… 처음부터 갈 곳이 없었던 것도 아닌데…… 다만 아내가 없어서…… 내가 잘못했어…… 마지막에 기회를 놓쳤지…… 아이야! 나는 이만 실례하지!
……
가와이: 너도 조심하지 않으면 저렇게 된다.
히라야마: 그럴 리가, 나는……
```

### 범례 C: 딸의 되받아침(61장면)
```
미치코: 그렇게 말해 봤자 어쩔 건데요? 말씀드리죠, 아빠, 저는 지금 시집갈 생각 전혀 없어요, 시집가고 싶지도 않아요. 아빠도 그렇게 생각하시잖아요?
히라야마: 뭘?
미치코: 내가 그냥 여기 남는 편이 더 좋다고……
히라야마: 왜? 그런 게 아니야.
미치코: 분명히 그렇잖아요. 내가 시집가면, 아빠와 가즈오는 어쩌라고요?
히라야마: 어떻게든 되지.
미치코: 어떻게든 된다고 해도, 도대체 어떻게 되는데요? 어떻게 해도 안 되잖아요. 아빠는 도대체 언제부터 그런 생각을 하신 거예요?
```

### 범례 D: 놓침(75장면)
```
미우라: 그럼, 좀 더 일찍 말해 줬어야지…… 내가 넌지시 물어본 적 있잖아, 그런데 그때 네가, 그 애는 당장은 시집 안 간다고 하지 않았어?
고이치: 그랬나, 내가 그런 말을 했나?
미우라: 했지, 했어. 미치코 씨도 그렇게 말하더군——야, 맥주 한 병 더.
고이치: 오——（호출 벨을 누름）그랬군. 참 잘못됐지……
미우라: 정말 너무 아깝군, 좀 더 일찍 말해 줬으면…… 돈가스, 하나 더 되나?
```

### 범례 E: 수용(77–79장면)
```
미치코:（얼굴을 들고, 미소 지으며）괜찮아요, 아빠…… 그렇다면 됐어요…… 나중에 후회하고 싶지 않을 뿐이에요…… 물어봐 주셔서 다행이에요.
……
고이치: 울리기라도 하면 어쩌나 했지.
히라야마: 음, 나도 좀 더 실망한 기색이려니 했어.
고이치: 별로 개의치 않는 것 같더군.
히라야마: 응, 그럼 됐지.
가즈오가 온다.
가즈오: 무슨 일이야? 언니가 우는 것 같아.
히라야마와 고이치가 서로 얼굴을 바라보고, 히라야마가 일어나 나간다.
……
히라야마가 나가, 복도에 멈춰 서서, 거기서 하늘을 한 번 올려다보고, 방으로 돌아온다.
```

### 범례 F: 거울 앞(88장면)
```
미치코:（감회가 가득하여）아빠……
히라야마:（미치코의 손을 잡고）그래, 알겠다…… 잘……
미치코가 말없이 고개를 끄덕인다.
히라야마: 자, 가자……
이어서 고이치, 히라야마, 미치코, 아키코가 차례로 나간다.
사람 하나 없는 실내——
```

### 범례 G: 결말(92–98장면)
```
가오루: 오늘은 어디서 돌아오시는 거예요?——장례식인가요?
히라야마: 응, 아아, 그런 셈이지.
……
군함행진곡이 울린다.
취한 손님 A: 오오, 대본영 발표인가……
취한 손님 B: 제국 해군은 오늘 아침 다섯 시 삼십 분, 미나미토리시마 동쪽 해상에서……
취한 손님 A: 졌구나.
취한 손님 B: 그래…… 졌구나.
……
가즈오: 몸조심하세요——돌아가시면 저 곤란하거든요.
히라야마: 오, 괜찮다. 헤이, 공격이든 수비든, 다 강철이지……
가즈오: 아, 그만하세요, 주무세요.
히라야마: 음…… 따따따라, 따따따라, 따따, 따따라……
여전히 그자리에 늘어져 끊임없이 흥얼거린다.
가즈오: 이제 그만하세요, 정말 주무셔야죠.
히라야마: 음…… 외톨이로구나…… 따따따라, 따따따라, 따따, 따따라……
입으로는 여전히 흥얼거린다.
97　이층 복도
온통 어둑하다……
98　이층 방
여기도 온통 어둑하고, 전신 거울이 어둠 속에서 희미한 빛을 낸다.
```
